Community Application Portal

Web application · form-to-review workflow · Google Sheets log

Built a small web app to make applications for a private community easier to submit and review. Instead of collecting requests through messages, applicants complete a structured form and each submission is recorded in a Google Sheets log.

The review page reads the submitted details into one view, so I can check an application and mark it accepted or declined. The project gave me hands-on practice connecting a front-end form to a simple data workflow and building a clear admin review step.

Invoice & Receipt Generator

Point-of-sale app · built in one day · in real use

At work, the main POS system went down. The shop had to open the next morning. No system meant no way to issue receipts — no way to sell.

So I wrote one. Plain HTML, CSS, JavaScript. Arabic RTL interface, multi-user login, sequential invoice numbers, VAT-inclusive pricing, live receipt preview, print output, and every receipt saved locally in the browser so nothing was lost when the real system came back online.

It worked the next morning. The shop sold. When the real system came back, the saved receipts were used to log every sale.

Linux on a PlayStation 4

CachyOS on locked hardware · working

A PlayStation 4 does not want to run Linux. Locked boot process, no normal install path, and most public guides assume a different hardware revision — following them just bricks the attempt.

The bottleneck was finding a bzImage and an initramfs that actually fit each other on this board. I tested combinations until a pair booted, then worked through storage, display output, and driver issues one at a time.

Result: an Arch-based Linux (CachyOS) running on the console. What I actually learned was the shape of the Linux boot chain and how to find answers when the guide doesn't exist yet.
